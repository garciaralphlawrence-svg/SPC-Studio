Measurements: one value per row (add a subgroup column such as "Hour" for X̄-R charts). Defectives: one row per sample with the number inspected and number defective. Pareto: a category column, with or without a count column.

Method

Standard Shewhart SPC. All calculations run in your browser and were checked against SciPy.

Control charts

I-MR (individual values): σwithin = M̄R / d₂ (d₂ = 1.128)

UCL/LCL = x̄ ± 3·M̄R/1.128  ·  MR: UCL = 3.267·M̄R

X̄-R (subgroups of 2–10): σwithin = R̄ / d₂

UCL/LCL = x̿ ± A₂·R̄  ·  R: UCL = D₄·R̄, LCL = D₃·R̄

p chart (proportion defective, sample size can vary):

p̄ = Σdefective / Σinspected  ·  limits = p̄ ± 3·√(p̄(1−p̄)/nᵢ)

Signal rules

    The range / moving-range charts use rule 1 only. Limits are calculated from all the data shown (Phase I).

    Capability

    Cp = (USL−LSL)/6σw   Cpk = min(USL−μ, μ−LSL)/3σw
    Pp, Ppk: same, using overall σ (sample standard deviation)
    Cpm = (USL−LSL) / 6√(s² + (μ−T)²)

    Expected PPM = normal tail areas beyond the specs × 10⁶. Z.bench = Φ⁻¹(1 − total tail). Sigma level = Z.bench(overall) + 1.5 (the Six Sigma 1.5σ shift convention).

    Rule of thumb: Cpk ≥ 1.33 capable · 1.00–1.33 marginal · < 1.00 not capable.

    Within vs overall: Cp/Cpk show what the process could do if it stayed stable; Pp/Ppk show what it actually delivered. A big gap means shifts or drift between subgroups.

    Normality

    Anderson–Darling test with the D'Agostino–Stephens small-sample adjustment. p < 0.05 means the data are probably not normal, so the PPM estimates should be treated with caution.
